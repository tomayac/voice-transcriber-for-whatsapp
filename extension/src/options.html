Voice Transcriber for WhatsApp

Transcribes WhatsApp Web voice messages on this device. Audio never leaves your computer; the model downloads once from Hugging Face.

Fallback model

Voxtral does not report the language it hears. This Whisper model identifies it, and transcribes the messages in languages Voxtral does not cover, such as Catalan. It loads in addition to Voxtral.

Languages

Language detection picks among these. Limiting it to the languages you actually receive avoids mix-ups between close languages, like Catalan and Spanish. With none selected, all languages count.

Behavior

With the Cross-Origin Storage extension installed, downloaded models are kept in storage that other sites using the same models can share, so each model downloads once per browser.
